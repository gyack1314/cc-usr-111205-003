# 保序概率口径

同p先按权重合并，保序目标sum w*(y-q)^2。每个不同训练p为一个原始结点，拟合后共享块均值；预测用最大训练p<=输入p的结点拟合值，恰在结点取其值，即右连续阶梯。支撑外clamp取最近端点或按配置unestimable拒估，不能外推斜线。收缩使用原始p与该阶梯值。

issued_time为比较顺序的整数，不解释公历，所有train的最大签发时刻严格早于validation最小时刻。各折验证指标先按各行权重求和再除全部验证权重，不对折均值等权。外期Brier及log评分同样按行权重；分箱为左闭右开，最后一箱含1，ECE=sum箱权重/总权重*abs(加权结局率-加权预测概率)。区间只在冻结映射下按外期process重抽，不重选gamma。

domain只核对原概率、结局和过程，不拟合PAVA或评分。

## 数据分工

| 名称 | 用途 | 不用于 |
| --- | --- | --- |
| 开发窗过程（`development_processes`） | 前推折训练/验证、选gamma、最终映射拟合 | 外期评分 |
| 外期过程（`external_processes`） | 只在冻结映射上评分、描述性bootstrap | 切分、选参、块边界、权重、分箱边界 |

两类过程整组隔离，同一过程不得同时出现在两边；每折的 `train` 与 `validation` 也必须是互不相交的过程集合，且训练过程全部行的签发时刻严格早于验证过程全部行的签发时刻。缺行、未知过程或过程交叠一律报错，不做静默补洞。

## 加权保序块

1. 同一概率p的所有训练行先合并为一个结点：`weight=sum w`、`positive=sum w*y`、`该点均值=positive/weight`。合并发生在任何合并块判定之前，因此同p的不同结局或不同行序不会拆成两个值。
2. 结点按p升序排列；相邻结点均值严格下降时合并，直到块均值单调不降（PAVA）。块只由训练p与加权均值决定，与行的原始顺序无关。
3. 每块保存：`p_low`/`p_high`（块内最小/最大训练p）、`knots`（块内不同训练p）、`weight`（总权重）、`positive_weight`（阳性权重）、`calibrated`（块均值）。
4. 最优性条件（`certificate`）：块均值不降，并且对任意连续块区间[i,j]，`sum(positive_i..j)/sum(weight_i..j)` 落在 `q_i` 与 `q_j` 之间。报告同时给出核对过的区间数和违约清单，可直接用于复算。
5. 预测按右连续阶梯：取最大的训练结点p<=输入p 所在块的均值。块间不插值，看到验证结局后也不改插值方式。
6. 支撑范围外的输入：`clamp` 返回最近端点块的均值并标注 `clamped_*`；`unestimable` 返回null并标注 `unestimable_*`。报告把受影响的行走ID列在 `final_mapping.clamped_rows` 或 `final_mapping.unestimable_rows`。

## 收缩与选参

最终概率 `q=(1-gamma)*p+gamma*isotonic(p)`，候选gamma来自资料的 `shrink_candidates`，必须落在[0,1]内。gamma=0 时直接用原始p，因此即使支撑外配置为unestimable，gamma=0 的行仍可估。

每个开发内前推折：用该折训练过程重新拟合保序块，只在该折验证过程上按行权重累计平方误差。所有折的累计误差除以全部验证行的总权重得到该gamma的汇总Brier——不是先按折求均值再平均。同分用精确分数比较，选较小gamma。若某gamma在任一验证行上不可估，该gamma不参与选择并在报告中列出不可估行。

选完gamma后才在整个开发窗重新拟合最终映射；外期行不参与这次拟合。

## 指标与区间

- **Brier**：`sum w*(q-y)^2 / sum w`，同一组内按行权重加权。
- **校准误差ECE**：使用资料中预先锁定的 `bin_edges`，左闭右开、最后一箱含1。空箱保留在输出中（`rows=0`、统计量为null），边界不会因资料多少而调整。ECE=sum 箱权重/总权重 * |加权结局率-加权预测均值|。
- **log评分**：加权对数损失。若某行预测恰为0而事件发生，或预测恰为1而未发生，该组log损失明确为字符串 `"inf"`（JSON不能表示无穷），同时列出 `infinite_rows`；绝不替换成裁剪过的小正数。两端点与结局一致时贡献为0。任一行不可估时该组log损失为null并标 `unestimable`。
- **配对bootstrap**：按外期过程整体有放回重抽 `bootstrap_draws` 次，随机源为固定 `seed`。每次重抽沿用冻结的最终映射与已选gamma，不重新拟合、不重新选参、不重算块边界。输出最终-原始Brier差、ECE差、log损失差的2.5%/97.5%分位点；log差遇到无穷计为不可用并记录次数。该区间只描述冻结映射下的外期过程抽样差异，不含选参、块边界或重拟合带来的不确定性。若重抽样本因支撑外输入而不可估，相应次数计入 `nonfinite_draws`，不伪装成0。

## 改善归因

报告 `improvement_attribution` 并列三层，避免把开发集内的表观改善当留出证据：

| 层 | 资料 | 说明 |
| --- | --- | --- |
| `development_in_sample` | 整个开发窗，同一批行既拟合又评分 | 只表示在开发集上拟合得更好，通常乐观 |
| `development_out_of_fold` | 时间前推折的验证过程 | 用于选gamma并估计折外改善；仍不是外期 |
| `external_holdout` | 外期过程 | 开发映射冻结后的一次留出评分，是真正的留出改善证据 |

外期行即使被用来改概率，也只影响外期评分；`provenance` 字段逐项声明外期结局未用于切分、选参、块边界、拟合权重或分箱边界，并给出 `mapping_sha256` 与 `development_input_sha256` 供改档后复算核对。
